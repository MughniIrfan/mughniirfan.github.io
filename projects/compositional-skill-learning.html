ONGOING

Compositional Skill Learning

Learning reusable skills from 3D point dynamics without hand-defined symbolic domains, and selecting skills from scene point clouds and language for assembly and arrangement tasks.

Overview

Robot manipulation policies trained on demonstrations tend to behave as flat, task-specific mappings and fail on compositions they have not seen. Task-and-motion planners compose novel tasks reliably, but they need hand-written operators and privileged state. We study how to get reusable, TAMP-style operators from demonstrations and use them without privileged plans or masks. The method represents state and action in a shared, PointWorld-style point-flow space. The state is calibrated 3-D object points plus robot points obtained from forward kinematics. The action is a displacement of fixed gripper points, which a weighted Kabsch fit turns back into SE(3) and finger commands.

Offline: Operator Discovery

An object-only inverse-dynamics model reads object motion with the robot fully masked out. Its latents are chunked into object-centric stages by a hierarchical (HiLAM / settle-based) chunker and stored as an operator library. Each operator holds a skill latent, preconditions, effects and contact affordances. Demonstrations come from LIBERO and from cuTAMP-generated FMB board assembly in the same simulator. For FMB the planner's own task skeleton, [Pick, Place] for each piece followed by a retract, provides exact stage labels for evaluating the discovered segmentation.

Online: Composition and Execution

A language-model parser turns the instruction into relational goals. An Adapt / Compose / Decompose planner then composes operators from the library. A 3-D semantic grounding stage (SAM3, D³Fields descriptors, G3Flow tracking) binds each operator to objects, regions and contact points, and a region-aware flow-matching policy executes it as gripper point flow. A forward-dynamics verifier compares the observed object effect with the intended one and triggers retry or replanning.

Results So Far

Simulation only. Commanded point-flow actions replay expert demonstrations at 88.8% against 91.4% for 7-D actions. Object-only latents recover stage boundaries (F1@20 0.87 held out, 0.82 on unseen tasks; the rule-based baseline reaches 0.90 and 0.86). Closed-loop success rates: 37/50 against 32–40 for the baseline on privileged tracks, and 21/50 against 20–25 on perceived tracks. Precision insertion (FMB) is handled by the separate compliant-control track based on RIL methodology and also belief space robust insertion approaches.
